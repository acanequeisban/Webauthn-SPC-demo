¿Qué es SPC?

Secure Payment Confirmation (SPC) es una API web que permite la autenticación simplificada durante transacciones de pago. Está diseñada para escalar la autenticación entre comerciantes y producir evidencia criptográfica de que el usuario ha confirmado los detalles de la transacción.

Características principales:

  • Autenticación biométrica rápida y segura
  • Confirmación visual de los detalles del pago
  • Funciona con passkeys existentes
  • Reduce el fraude en pagos online

Cómo empezar

1. Crear una cuenta 2. Registrar una passkey 3. Realizar un pago con SPC

Requisitos

Navegador compatible: Chrome 95+, Edge 95+, o cualquier navegador basado en Chromium con soporte para SPC habilitado.
Autenticador requerido: Necesitas un dispositivo con autenticación biométrica (huella digital, Face ID, Windows Hello, etc.).
